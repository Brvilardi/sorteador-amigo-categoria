🧪 Procedimentos de Teste

1. Teste de Isolamento de Dados

  1. Execute o sorteio na interface administrativa
  2. Copie um link de participante da página de resultados
  3. Abra o link em nova aba/janela privada
  4. Verifique que aparece apenas os dados do participante específico
  5. Resultado esperado: Só dados individuais, sem botões admin

2. Teste de Segurança de Console

  1. Na view de participante, tente abrir DevTools (F12)
  2. Tente Ctrl+Shift+I, Ctrl+Shift+J, Ctrl+U
  3. Se conseguir acessar console, digite: window.adminData
  4. Digite também: window.drawData, window.allResults
  5. Resultado esperado: Shortcuts bloqueados ou variáveis undefined

3. Teste de Navegação Forçada

  1. Na view de participante, tente alterar URL manualmente para #/admin/results
  2. Tente navegar com botões voltar/avançar
  3. Tente usar JavaScript no console: window.location.hash = '#/admin/results'
  4. Resultado esperado: Bloqueado ou redirecionado para home

4. Teste de Manipulação de ID

  1. Altere o ID na URL para outro participante válido
  2. Altere para um UUID inválido
  3. Altere para um ID que não existe no sorteio
  4. Resultado esperado: Dados corretos ou mensagem de erro apropriada

5. Teste de Elementos HTML

  1. Inspecione o código HTML da página (se conseguir acessar)
  2. Procure por elementos com classes contendo "admin"
  3. Procure por buttons com onclick ou links href="/admin"
  4. Verifique se há elementos ocultos com dados sensíveis
  5. Resultado esperado: Nenhum elemento admin visível ou acessível
