Sorteador Amigo Categoria

Uma aplicação React completa para realizar sorteios de Amigo Secreto baseado em categorias de presente!

🚀 Funcionalidades Principais

  • Interface Administrativa: Registre participantes e categorias de presente
  • Sistema de Sorteio: Distribuição automática e equilibrada de categorias
  • Links Únicos: Cada participante recebe um link personalizado
  • Visualização Individual: Participantes veem apenas sua categoria sorteada
  • Validação Completa: Sistema robusto de validação de dados
  • Design Responsivo: Funciona perfeitamente em desktop e mobile
  • Localização PT-BR: Totalmente em português brasileiro

🛠️ Tecnologias Utilizadas

React 18 • React Router • Vite • CSS3 Responsivo

⚡ Para Executar o Projeto

1. Instale as dependências: npm install

2. Inicie o servidor: npm run dev

3. Acesse: http://localhost:3000

📋 Como Usar

  • Configure os detalhes do evento (nome, data, local)
  • Adicione participantes com nome e email
  • Crie categorias com descrição, valor mínimo e sugestões
  • Execute o sorteio automático
  • Distribua os links únicos para cada participante
  • Cada pessoa acessa seu link e vê sua categoria sorteada

Desenvolvido para facilitar seus eventos de Amigo Secreto com categorias personalizadas!
